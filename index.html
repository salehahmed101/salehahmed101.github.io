The project

Animal Weight Tracker is a University of Bolton academic project. The original desktop screens establish its identity and show how the application is organized.

The interface

The navigation separates organization and animal areas, with entries for animals, courses, meals, exercises, species, and activity. A staff-information view combines a table with a dedicated entry form.

The form structure

The visible form groups ID, name, age, designation, and organization with Save and Close controls. These screenshots show the interface; they do not establish a particular programming language, database, or measured outcome.

Animal Weight

A simple question: how can a list of measurements become easier to read?

This browser prototype explores that idea with a chart and an accessible table. It is a new companion to the desktop project shown above, not the original university application.

↳

Fictional sample data. Changes stay in this tab and disappear on reload.

Read the design notes +

The interaction

Add a dated measurement. The timeline sorts chronologically, updates the chart, and announces the change. The table provides the same information without depending on color or a graph.

The boundaries

This is a small client-side experiment, not a saved animal record or a health assessment. There is no account, database, or tracking request.

The implementation

Native form inputs, validation, an SVG chart, and in-memory JavaScript state. Duplicate dates and invalid weights are rejected instead of silently changing an existing record.
